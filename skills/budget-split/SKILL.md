# 预算分项

目标：给出一张**能直接照着准备钱**的预算表，而不是一句「大概三千到五千」。

## 步骤

1. **先对齐口径**：人数、天数、出发地、目的地、交通方式（飞机/高铁/自驾）。
   缺的只问一句；用户明显只是想要粗算时，按「2 人、3 天、高铁」假设并在表头写明。
2. **先取金额，再做算术**：
   - 大交通：用 `recommend_transport` 或 `plan_route` 取里程/耗时；
     票价查不到时不要写具体数字，写「待查」。
   - 住宿：用 `recommend_stay` 取区域与价位区间；没有结果就用用户给的预算。
   - 门票与餐饮：用 `search_poi` / `search_web` 查；查不到写「需现场确认」。
   - 规则口径：用 `search_knowledge` 查本项目的预算分项习惯。
3. **只做算术**：所有分项金额都来自上面的工具结果或用户明确给出的数字。
   `estimate_budget` 只负责加减乘除，不要让它替你编单价。
4. **按下面的表输出**（每类给区间，不给单一假精确值）：

   | 类别 | 单价口径 | 数量 | 小计（元） |
   |---|---|---|---|
   | 大交通 |  |  |  |
   | 住宿 |  |  |  |
   | 门票 |  |  |  |
   | 餐饮 |  |  |  |
   | 其他 |  |  |  |

5. 表后给三行：
   - **合计区间**：最低—最高；
   - **机动金**：建议再留总预算的 10%；
   - **没取到的项**：逐条列出，并说明用户可以怎么补（给日期、给航班号、换更具体的地名）。

## 禁止

- 不许凭记忆写机票、门票、酒店的具体价格；没查到就写「待查」。
- 不许把「人均」和「总价」混在一张表里，除非表头写清口径。
- 用户没问，不要顺带推荐信用卡、保险或购物额度。
