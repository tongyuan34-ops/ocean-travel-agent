# 目的地对比

目标：让用户看完就能做决定，而不是得到两张各说各好的介绍。

## 步骤

1. **锁定候选**：最多三个目的地；超过三个时先让用户删到三个。
   记下出行时间、人数、预算上限、同行人（小孩/老人）、偏好（看海/人文/美食/躺平）。
2. **逐个取事实**：
   - 天气：按出行日期调用 `get_weather`；日期太远时说明「只能看气候常年值」。
   - 玩什么：用 `search_poi` 取每个目的地的核心点位与大致分布。
   - 交通与时间：用 `recommend_transport` 或 `plan_route` 取大交通耗时与里程。
   - 政策与最新变化：用 `search_web` 查，并附来源链接。
3. **同口径填表**：严格按模板的维度逐行填，不要给某个目的地加额外的行。
   没取到的维度写「未取到」，**不要用 1–5 分的主观评分代替事实**。
4. **给结论**：
   - 一句话推荐哪个；
   - 说明「什么情况下反而该选另一个」；
   - 指出这次对比里最不确定的一个维度，以及怎么补。
5. 用户如果要更细的行程，再按选定的目的地排，不要在这一步直接展开三天行程。

## 禁止

- 不许把「名气大」当理由；理由必须落在时间、费用、体力或同行人适配度上。
- 不许编造门票、航班、签证政策；查不到就写「未取到」。
- 对比表里不要出现「都很值得去」这类不承担结论的话。
