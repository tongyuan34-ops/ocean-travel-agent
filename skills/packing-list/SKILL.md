# 行前清单

目标：给出一份**能打印出来逐项打勾**的清单，而不是一段「记得带好证件」。

## 步骤

1. **补齐三个信息**：目的地、出行时间/季节、同行人（是否有小孩或老人）。
   天数缺省按 3 天；活动类型（海边、徒步、自驾、城市漫步）用户没提就按目的地常识列，
   并在清单开头注明「按常规假设」。
2. **天气只查不猜**：出行日期在天气预报范围内时，调用 `get_weather`；
   日期太远就说明「按常年气候准备」，不要编一个温度。
3. **调用技能工具生成清单**：`skill__packing-list__build`，
   参数填 `destination`、`days`、`season`、`companions`、`activities`。
   工具会套用项目模板并追加条件项（小孩、老人、海边、徒步、自驾）。
4. **交付方式**：
   - 默认把清单正文直接展示给用户；
   - 用户明确要文件时，再调用 `write_file` 保存成 `.md`，路径由用户给；
   - 在文件真正写成功之前，不要声称「已保存到桌面」。
5. 最后用一句话提醒：出发前 24 小时再核对证件、药品和充电设备。

## 禁止

- 不要输出与目的地无关的通用长清单；条件项由工具按同行人和活动追加。
- 不要把「建议购买」写成「必须携带」，除非是证件、药品这类硬性项。
- 不要重复整份清单两次（一次正文、一次文件说明），说明只给文件路径。
